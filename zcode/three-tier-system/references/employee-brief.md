# 员工派发卡

首次派活、切换包类型或改变写入并发时读取。正式员工合同唯一维护于 `../profiles/employee.md`；ZCode 加载副本是 `~/.zcode/agents/employee.md`，本页只定义创建方式和任务包。

## 创建

优先：

`Agent(subagent_type:"employee", run_in_background:true, prompt:<任务包>)`

仅当角色返回 `not found` 时，把正式合同全文与本页任务包拼接后交给 `general-purpose`。退化角色不继承工具白名单和轮数；同一会话失败一次后不反复试。首次派发必须后台运行；续派只在上一轮结束后用 `SendMessage`。

## 共同字段

```text
工作包类型：READ | WRITE
当前活动写入数：0 | 1 | 2+
工作包 / 尝试 / 规格版本：<B-x / n / vN>
唯一指导文档：<worktree 外绝对路径，只读>
工作目录 / 分支 / 起始版本 / 预期工作区：<事实>
唯一结果与验收编号：<结果；R-x>
允许范围 / 禁止范围：<路径与动作>
规模停止线：<文件数、实际新增、实际删除>
最低成本验证：<命令；证明什么；影响哪个决定>
明确不运行：<未授权或重复的高成本命令>
持久化检查点 / 结束条件：<骨架、WIP、candidate、报告>
```

删除棒应分别估算生产代码与测试的真实删除量并留合理余量。

## READ 追加字段

```text
冻结源码快照：<固定 commit；并发写入时用独立只读 worktree；用户未提交改动用经理批准的清单或隔离副本>
起止快照校验：<如何确认读取期间未漂移>
搜索域 / 与其他调查的分界：<范围>
证据失效条件：<哪些快照、文件或候选变化会失效>
独占证据文件：<所有源码 worktree 外绝对路径；每包一个>
硬限制：项目与仓库只读；只向上述证据文件增量写结论
```

源目录全程无写入时可直接读取并做起止校验；变化目录不算冻结快照。没有可复核快照时，不派否定性搜索。

## WRITE 追加字段

```text
只读集合 / 排他写入集合：<范围>
资源授权与持有区间：<test/device/dependency/integration；无则 NONE>
candidate 要求 / 证据失效条件：<要求>
```

活动写入数为 `2+` 时再加：

```text
lane / 前置工作包：<W-x / 列表>
共享契约版本 / 其他活动 lane 与写集合：<C-x / 仅用于避让>
资源槽令牌：<唯一容量单元；无则 NONE>
预定集成顺序：<要求>
```

第二个 `WRITE` 派出前，经理必须已通过并行判定，并登记独立 worktree、写租约、资源与集成顺序。

## 派发前核对

- 只包含当前一棒，没有“顺便做下一步”。
- 未授权的重型测试、设备、依赖/缓存和集成资源明确写 `NONE`，不留空。
- 员工返回后由经理独立验收；任务包不要求员工宣布项目通过或完成。
