# 三级体系运行模板

启动或维护三级体系时读取。按任务删去不适用字段，不保留空占位。

## 唯一指导文档

```markdown
# <任务名>：唯一执行指南

## 当前状态

- 项目 / 工作包状态：<DRAFT...DONE> / <READY...INTEGRATED>
- 规格 / 工作包 / 尝试 / 类型：<S1 / B1 / A1 / READ|WRITE>
- 经理任务 / 员工任务：<ID / ID或NOT_CREATED>
- 回报方式：<主动上报 / 有界等待 / heartbeat / 子agent通知 / NOT_AVAILABLE>
- 临时监督：<ID、绑定身份、失效条件、清理状态；无则NONE>
- 当前动作 / 所有者 / 下一动作：<值>
- 用户待决 / 当前阻断：<无则NONE>

## 用户结果与边界

- [ ] R-01 <用户可感知结果与可验证条件>
- 明确不做：<范围>
- 已接受风险/决定：<日期、结论、用户影响>

## 事实基线

- 项目 / 员工目录：<项目ID或路径 / 绝对路径>
- 分支 / 起始HEAD / 工作区：<事实>
- 用户已有改动与归属：<值>
- 指导文档访问：<经理可写、员工可读、只读能否强制>
- 项目规则 / 验证政策：<值>

## 活动工作包

- 唯一结果 / 验收编号：<值>
- 允许范围 / 禁止范围：<值>
- 规模停止线：<文件数、新文件、增删量或其它>
- 复用证据 / 最低成本新验证：<证据；证明什么；改变哪个决定>
- 明确不运行 / 扩大触发条件：<值>
- 收口条件：<验证通过且无扩大条件即READY_FOR_MANAGER_REVIEW>

READ追加：冻结输入与起止校验；搜索域；独占证据位置；失效条件。

WRITE追加：读写范围；candidate要求；资源授权；预期结束状态。

## 证据账本

| 验证 | 绑定状态 | 证明什么 | 改变哪个决定 | 重跑/扩展原因 | 结果 |
|---|---|---|---|---|---|
| V-01 | <HEAD/candidate> | <行为/风险> | <决定> | 首次 | PLANNED |

## 执行记录

只追加改变状态或决定的事件：员工交付事实、经理审查、退回、集成、阻塞、规格/所有权/监督机制变化。长日志留在外部证据。

员工交付：类型、起点/HEAD/candidate、文件与验收映射或搜索覆盖、验证原始结果、NOT_TESTED/BLOCKED、遗留进程、失效条件。

经理审查：磁盘事实、固定差异、必要新验证、收口检查、结论（REVIEW_PASSED/REVIEW_RETURN/BLOCKED）。

集成：源candidate、目标分支与预期HEAD、方式/执行者、实际命令与结果、目标新HEAD、组合验证、结论（INTEGRATED/BLOCKED）。

## 完成条件

- [ ] 用户结果已有集成实现和有效证据，或偏差获用户接受。
- [ ] REVIEW_PASSED 未冒充 INTEGRATED；最终目标HEAD已核对。
- [ ] 未验证项、剩余风险和工作区状态已披露。
- [ ] 最终对抗式审查已完成，扩展验证都有触发原因。
- [ ] 员工、遗留命令和临时监督已收口；未执行越权合并、发布或清理。
```

## 员工工作包

```text
你是员工执行层，不是需求负责人、总账维护者或最终审查者。

唯一指导文档：<绝对路径，只读>。先读项目AGENTS.md和该文档。

接手核对：
- 目录 / 分支 / 起始HEAD / 预期工作区：<事实>
- 规格 / 工作包 / 尝试 / 类型：<Sx / Bx / Ax / READ|WRITE>
- 唯一结果 / 验收编号：<值>

READ：冻结输入与起止校验、搜索域、独占证据位置、失效条件。
WRITE：允许读写、禁止范围、candidate要求、资源授权。
规模停止线：<值>

验证预算：
- 复用 / 只新增 / 明确不运行：<值>
- 新验证证明：<行为或风险>；结果决定：<提交/退回/阻塞>
- 只在实现或环境变化、新失败、矛盾证据或旧证据失效时扩大。
- 同一代码状态每项计划验证默认一次；通过且无扩大条件时立即收口。

遇到歧义、越界、高风险、输入变化、证据矛盾、停止线或结果不明，停止新增并报告BLOCKED；保留现场，不重试、清理或扩大。

完成后停止。WRITE形成candidate；READ不制造源码提交。只报告：目录、分支、起点/HEAD、状态、candidate或搜索覆盖、文件与验收映射、验证原始结果、NOT_TESTED/BLOCKED、遗留进程、失效条件和剩余风险。只写READY_FOR_MANAGER_REVIEW，不宣布REVIEW_PASSED、INTEGRATED或DONE。

回报目标：<经理任务ID或实际入口>。主动上报可用时，在本任务留报告并把精简状态发给经理；否则使用已记录的降级入口，不依赖用户转发。
```

## 经理控制指令

### 收缩/纠偏

```text
CONTROL-<n>｜<工作包/尝试/规格>
继续允许：<范围>；立即停止：<范围>；保留并报告：<现场>
只报告新增差异、新证据、唯一阻断和未测项。无阻断且计划验证已完成时立即交付；不要清理未知改动或进入下一棒。
```

### 审查退回

```text
REVIEW_RETURN-<n>｜绑定candidate：<提交>
全部已证实阻断：<列表>；只允许修：<最小范围>
复用证据 / 唯一新增验证：<值>
停止条件：形成新candidate并READY_FOR_MANAGER_REVIEW，或BLOCKED。
```

### 串行集成

```text
INTEGRATE-<n>｜源candidate：<完整提交>
目标目录/分支/预期HEAD：<值>；依赖/方式/唯一执行者：<值>
禁止自行解冲突、改变业务语义、扩大范围、重写历史或顺手清理。
目标变化、冲突、证据失效或结果不明即BLOCKED。
回报实际命令、退出状态、目标新HEAD、组合差异和工作区状态。
```
